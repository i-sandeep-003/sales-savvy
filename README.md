# Sales Savvy 🛒  
**Full-Stack E-Commerce Application**

## 📌 Project Overview
Sales Savvy is a full-stack e-commerce web application developed to understand how real-world online shopping systems work.  
The application allows users to browse products, add them to a cart, and manage orders through a clean and simple workflow.

This project was built as part of my learning journey in **Spring Boot and React**, focusing on backend APIs, frontend integration, and database operations.

---

## 🛠️ Tech Stack

### Backend
- Java  
- Spring Boot  
- Spring Web (REST APIs)  
- Spring Data JPA  
- Hibernate  
- MySQL  

### Frontend
- React JS  
- HTML, CSS  
- JavaScript  

### Tools & Others
- Maven  
- Git & GitHub  
- Eclipse IDE  
- Postman  

---

## ✅ Features
- User-friendly product listing  
- Add products to cart  
- Cart management (add/remove items)  
- Backend REST APIs for products and cart  
- Database integration using MySQL  
- Clean layered architecture (Controller, Service, Repository)  

---

## 📂 Project Structure
- **Controller Layer** – Handles API requests  
- **Service Layer** – Business logic  
- **Repository Layer** – Database interactions  
- **Entity & DTOs** – Data modeling
